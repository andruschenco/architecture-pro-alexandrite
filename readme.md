## Легенда

| Обозначение       | Значение                                |
|-------------------|-----------------------------------------|
| ⏱️ **2-30 минут** | Известное время (из описания)           |
| ⏱️ **Неизвестно** | Время не указано в исходных данных      |

## Выводы

1. **Единственный этап с известным временем** — `PRICE_CALCULATED` (2-30 минут)
2. **Все остальные этапы** не имеют временных меток в описании
3. **Основная проблема** — неизвестно, сколько времени занимает:
    - Согласование (`MANUFACTURING_APPROVED`)
    - Ожидание оператора (`MANUFACTURING_STARTED`)
    - Само производство (`MANUFACTURING_COMPLETED`)
    - Упаковка и доставка (`PACKAGING` → `SHIPPED`)
    - Закрытие заказа (`CLOSED`)

## Рекомендации

Для выявления узких мест необходимо:
1. Добавить логирование времени перехода между статусами
2. Измерять фактические задержки на каждом этапе
3. Настроить мониторинг времени жизни заказа в каждом статусе
